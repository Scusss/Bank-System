JABBank is a student software project that demonstrates how an online banking application works: registering, identity verification steps, deposits, withdrawals, transfers and receipts. All balances and transactions are simulated.

Technology

Built with Python (Flask), a PostgreSQL database and Supabase, and hosted on Render.

Please note

Because this is a demonstration, you should use made-up information only. Do not enter real passwords you use elsewhere, real ID numbers or real bank details.
